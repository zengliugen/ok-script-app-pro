# <能力名> 实施偏差记录

| 字段 | 值 |
|---|---|
| 状态 | 草稿 |
| 关联能力 | <能力名> |
| 创建日期 | YYYY-MM-DD |
| 更新日期 | YYYY-MM-DD |

对应计划：`plans/<能力名>-plan.md`。本文件按**时间倒序**追加，最新一条在最上面。

## 准入判据

只有「实际做法 ≠ 计划」才记。日常调试、按计划推进的过程不记。

---

## #1 偏差标题

| 字段 | 值 |
|---|---|
| 日期 | YYYY-MM-DD |
| 类型 | 前提失效 / 更优路径 / 范围变更 |

**触发场景**：在做什么事时发现了什么。

**原计划**：计划里写的是怎么做。

**实际做法**：改成了什么。

**原因**：为什么必须改。若是实测结论，附可复现命令。

**影响**：
- 计划中哪些批次受影响
- 是否引入新风险
- 是否需要新写 ADR（决策被推翻时必填）
