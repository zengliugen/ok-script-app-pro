# templates/ —— 文档模板

复制对应模板到目标目录后改名，不要直接编辑本目录下的文件。

| 模板 | 复制到 | 改名规则 |
|---|---|---|
| `design.md` | `design/` | `<能力名>.md` |
| `plan.md` | `plans/` | `<能力名>-plan.md` |
| `deviation.md` | `plans/` | `<能力名>-deviation.md` |
| `testing.md` | `testing/` | `<能力名>-testing.md` |
| `adr.md` | `decisions/` | `NNNN-<slug>.md` |

## 模板里为什么有话术

模板中形如「一句话说明要解决什么问题」的句子是**填写提示**，不是要保留的内容。
保留它们会让文档看起来完整、实际上什么都没说——这类文档比没有文档更有害。

## 修改模板

模板是本目录结构的规范载体，改动模板等于改动「文档该长什么样」。
改动前先确认是否需要同步更新本目录上级的 `README.md`（文件头字段、命名规范两节）。
