## 要解决的问题

具体现象或缺口。不要写「想加个功能」——那句话通常意味着问题还没界定。

- 现象：上游 `src/config.py` 的 `make_bottom_right_black` 把 UID 遮挡区写死为
  「右下角、宽 13% × 高 2.5%」。换游戏或改分辨率后，UID 不在这个位置，遮罩就挡了个空；
  反过来它还可能挡住需要识别的内容。用户没有任何调整入口。
  本仓库曾实现过一版可配置遮罩（`extensions/core/screenshot_mask.py` 与
  `extensions/ui/screenshot_mask_tab.py`），但该实现从未提交，源码在 2026-10-30 的
  `refactor(extensions): 代码按能力分包` 前后丢失，仅剩
  `extensions_tests/__pycache__/TestScreenshotMask.cpython-312.pyc` 与运行时配置
  `configs/Screenshot Mask.json`（后者被 gitignore 忽略）。按 `git fsck`、reflog
  与全盘搜索确认无任何可恢复副本。

- 不做的后果：每个用户只能改源码里的两个魔数，或干脆关掉遮罩泄漏 UID。升级上游时
  这两行还会被覆盖，改动反复丢失。

| 配置键一律改为英文（`Enable Mask` / `Mask Anchor` / `Mask Width` 等），并在启动时把旧中文键的值迁移过来 | 体检的「配置键」项硬性要求键为可打印 ASCII：中文键会原样写进持久化 JSON，日后无法安全改名。旧 json 里存着用户已调好的值（宽 40.21、高 24.26、内缩 30.94/40），直接丢弃等于让用户重调一次 | 旧键名（中文）在新代码里以常量形式保留并只用于迁移读取；迁移后旧键删除 |
| 页签保持 Game 分区末位，不强行排到「模板」页签下方 | 当前框架把 `TemplateTab` 放在 Develop 分区（`MainWindow.py:177`），自定义页签只能落在 Game 分区（`add_page(..., SECTION_GAME)`）。跨分区不存在「上下相邻」，强行移动会让一个游戏相关页面出现在「开发」区。语义上「Game 分区末位」即「游戏类页面的最后一个」 | 上游若把模板页签移回 Game 分区，需重新评估 A8 |
| 单位固定百分比，不提供像素与切换入口 | 需求 Q3 已明确；且多单位会引入「只存一套值」的换算歧义，拖拽回写时正反换算必然产生累积误差 | 无 |
| 编辑与保存分离：拖拽只改界面临时值，点「保存配置」才落盘 | 当前实现「编辑即生效」使「重置为配置值」按钮失去意义，误拖无法撤销。分离后两个按钮各自语义清晰 | 「启用遮罩」开关不参与这套机制，仍即时落盘 |
| 遮罩失败必须吞掉异常、原帧返回 | 遮罩是装饰性后处理，配置异常或帧为空时让截图整体失败会连带毁掉任务与模板采集 | 异常需写日志，不得完全静默 |

## 结论

一句话说清做什么、不做什么。**结论为空时不允许建立能力文档**——那意味着还没有确认任何东西。

- 做：在 `extensions/capabilities/screenshot_mask/` 重建截图遮罩能力——可开关、
  8 锚点 + 宽高 + 偏移的百分比几何、`screenshot_processor` 覆写、侧边栏可视化页签
  （开关 + 缩放工具条 + 可拖拽 8 手柄的画布 + 保存/重置），配置键英文并迁移旧中文键的值。

- 不做：不改上游 `src/config.py`、不做 patch、不提供像素单位与单位切换、不实现 Web 编辑器、
  不实现设置卡片折叠（当前框架不具备）。
